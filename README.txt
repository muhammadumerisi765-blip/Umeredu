# Nova Studio Website

Files:
- index.html
- style.css
- script.js
- sitemap.xml
- robots.txt
- README.txt

SEO setup:
- sitemap.xml contains the deployed Netlify homepage URL.
- robots.txt allows search engines to crawl the website.
- robots.txt points Google and other search engines to sitemap.xml.

Open index.html in any modern browser.
